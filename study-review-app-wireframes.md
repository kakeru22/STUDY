# 一問一答復習アプリ ワイヤーフレーム

## 1. 前提

- 対象: `個人用`
- 形態: `1つのPWA`
- 主操作端末: `スマホ`
- 補助端末: `PC`
- 同期先: `Google Drive`
- 起動方針: `オフライン優先`

このワイヤーフレームは `スマホ1カラム` を基本とし、必要な箇所だけ `PC差分` を記載する。

## 2. 画面一覧

- `WF-01` ホーム
- `WF-02` 問題追加
- `WF-03` 問題一覧
- `WF-04` 問題編集
- `WF-05` 復習開始
- `WF-06` 復習出題
- `WF-07` 復習結果
- `WF-08` 同期 / 設定
- `WF-09` 競合ダイアログ

## 3. 共通UI

### 3.1 ヘッダー

```text
+--------------------------------------------------+
| Logo                    同期: オフライン / 未同期 |
+--------------------------------------------------+
```

表示ルール:

- 常に `同期状態` を右上に出す
- 状態は `オンライン` `オフライン` `同期中` `未同期あり` `競合あり`

### 3.2 下部ナビゲーション

```text
+--------------------------------------------------+
| [ホーム] [追加] [一覧] [復習] [設定]             |
+--------------------------------------------------+
```

### 3.3 同期ステータスバー

```text
+--------------------------------------------------+
| オフラインモードで起動中                         |
| 未同期の変更: 12件   最終同期: 2026-07-23 21:20 |
| [オンラインに戻る] [今すぐ同期]                  |
+--------------------------------------------------+
```

表示条件:

- `オフライン`
- `未同期あり`
- `競合あり`

## 6. 状態別ルール

### 6.1 オフライン

- 起動は常に `IndexedDB` 優先
- ホーム、問題追加、一覧、復習はすべて利用可能
- Drive操作だけ保留

### 6.2 未同期あり

- 目立つ位置に件数表示
- 復習結果画面で `ローカル保存済み / 未同期` を出す
- 設定画面から再同期できる

### 6.3 競合あり

- 自動同期しない
- 競合ダイアログを出す
- 勝手に上書きしない

## 7. 実装メモ

### 7.1 モバイル優先で重要な点

- フォーム入力中にキーボードでレイアウトが崩れない
- `保存` と `正解選択` のボタンを大きくする
- スクロールが長くなるので詳細項目は折りたたむ

### 7.2 最初の実装順

1. 共通レイアウト
2. ホーム
3. 問題追加
4. 問題一覧
5. 復習
6. 同期 / 設定
7. 競合ダイアログ

### 7.3 次に必要なもの

- コンポーネント分割案
- 画面ごとの状態一覧
- IndexedDBスキーマ
- Drive API連携フロー
